Question workflow

Published revisions are immutable. Corrections create a new draft revision tied to the exact historical content it supersedes.

Import staging

Structured imports never publish directly

Batch fingerprints make ingestion idempotent. Row fingerprints catch duplicates before any imported content can become a draft question.

  5. Preview

  8. Review

Raw rows, mapping data and answer-bearing import payloads remain private.

Safe administration

Revision, quarantine and audit

RevisionPublished content is corrected by creating a new draft revision, not by mutating history.
QuarantineProblematic published questions are quarantined rather than deleted.
AuditContent-critical actions record actor, action, entity and structured details in an append-only private log.
