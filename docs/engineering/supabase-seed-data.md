`supabase/seed.sql` contains deterministic synthetic fixtures only. M2 seed data represents the approved Midwifery programme, representative subjects, nested topics, synthetic development questions, a synthetic source record, and matching private synthetic answer keys.

The fixtures are not real NMCN examination content and contain no real student PII. Staging must continue to use synthetic or explicitly sanitized data until later launch controls authorize otherwise.
